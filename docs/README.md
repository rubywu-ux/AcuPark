# Documentation

This folder contains all the documentation for the AcuPark project.

## Structure

-   **[project/](project/)**: Contains high-level project documentation.
    -   `USER_FLOWS.md`: Every screen and path in the app today (pay ahead, scan, pay now, reserve, navigate, settings).
    -   `PROJECT_BRIEF.md`: The original project requirements and brief, with current status.
    -   `MASTER_PROMPT.md`: The master prompt used for AI context.
-   **[technical/](technical/)**: Contains technical details and diagrams.
    -   `FIGMA_MCP_USAGE.md`: How the Figma MCP connection is set up and used.
    -   `MCP_EXPLAINED.md`: Explanation of the Model Context Protocol usage.
    -   `VIBE_CODING.md`: The Vibe Coding process used to build AcuPark.
    -   `mcp_diagram.svg`: Architecture diagram for MCP.
-   **[CREDITS.md](CREDITS.md)**: Map data and photo sources.

## Root Files
-   `../README.md`: The main entry point for the project (setup, usage).
